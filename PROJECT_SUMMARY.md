#  EventAI - Project Summary for Judges

##  Project Name
**EventAI** - Intelligent Event Discovery Platform

##  Team Information
- **Project Type**: Full-Stack Web Application
- **Tech Stack**: React + Node.js + AI Integration
- **Duration**: Hackathon Project
- **Deployment**: Ready for production

##  Problem & Solution

### **Problem**
- 73% of people miss relevant events due to poor discovery
- Information overload in event platforms
- Generic recommendations without personalization
- Poor user experience in existing solutions

### **Solution**
AI-powered event discovery platform that learns user preferences and provides intelligent, personalized event recommendations using Google Gemini AI.

## ⚡ Key Features

### ** AI-Powered Recommendations**
- Google Gemini integration for intelligent suggestions
- User interest analysis and matching
- Personalized event curation
- Smart filtering algorithms

### ** Modern UI/UX Design**
- Glassmorphism design trends
- Smooth animations and micro-interactions
- Responsive mobile-first design
- Interactive event cards with hover effects

### ** Advanced Search & Discovery**
- Real-time search with debouncing
- Category-based filtering with emojis
- Tag-based event matching
- Location-aware suggestions

### ** User Experience Features**
- One-click RSVP system
- Favorite events management
- Toast notifications for feedback
- Loading states and skeleton loaders

### ** Real-time Data Management**
- Firebase Firestore integration
- RESTful API architecture
- Real-time event updates
- Scalable backend infrastructure

### **Frontend (React + Vite)**
```
├── Modern React 19 with hooks
├── Tailwind CSS for styling
├── Lucide React for icons
├── React Router for navigation
├── Responsive design patterns
└── Progressive Web App ready
```

### **Backend (Node.js + Express)**
```
├── RESTful API endpoints
├── Firebase Admin SDK
├── Google Generative AI integration
├── CORS enabled for cross-origin
├── Environment configuration
└── Error handling & logging
```

### **AI Integration**
```
├── Google Gemini 2.5 Flash model
├── User preference analysis
├── Natural language processing
├── Event metadata matching
└── Intelligent recommendation engine
```

### **Database (Firebase Firestore)**
```

```
